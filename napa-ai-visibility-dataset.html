Method

One automated scanner, the same one behind every free AO Audit scan, run against real, currently-operating, locally-owned businesses - not directory listings, not chains. Each town's roster was built and verified independently (see each report's own method notes for that town's specific inclusion and exclusion decisions). We publish aggregates only; no individual business's result is named here or in any report without that business's consent.

Honest limit: this is a snapshot of 257 businesses across seven towns as of the scan dates above, not a census of the region and not a permanently live dataset - if you're reading this months later, some of the underlying sites will have changed. The reports themselves carry each town's specific roster notes and exclusions in full.

FAQ

What is the Napa Valley AI-Visibility Dataset?

257 real, locally-owned businesses across seven Napa Valley and Solano County towns, each checked with the same automated tool for whether machines - including the AI tools people now ask for recommendations - can actually read them. It's the aggregate data behind our seven published Scan-the-Town reports, not a separate download, so it can be checked against the reports it came from.

How was this data collected?

The same automated scanner we use for every free AO Audit scan, run against real, verified, currently-operating businesses in each town between July 26 and August 17, 2026. Every business was checked for reachability, LocalBusiness structured data, an llms.txt AI-instructions file, visible prices, and a meta description. We publish aggregates only - no individual business's result is named without its owner's consent.

Can I use this data?

Yes, under a Creative Commons Attribution 4.0 license - credit The AO Audit and link back. If you want the underlying town-by-town breakdowns, they're already published: the links are on this page.

Why publish this as a dataset instead of just articles?

Because a claim and a dataset are different things. Anyone can write "most local businesses are invisible to AI." Fewer people publish the actual counts, the method, and a license to check it. That's the whole point of Answer Optimization done honestly - verifiable beats persuasive.
